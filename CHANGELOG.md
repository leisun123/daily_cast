# Changelog

All notable changes to DailyCast are documented in this file.

## v0.1.0-alpha

- Complete AI podcast generation pipeline from news collection through review-gated episode creation.
- Deterministic filtering, deduplication, event clustering, and structured LLM editorial workflow with validated result caching.
- Resumable TTS segment generation, cached audio artifacts, and FFmpeg MP3 assembly.
- Self-hosted RSS publishing with immutable media assets, atomic Feed updates, and crash reconciliation.
- Docker Compose deployment with Alembic migrations, health checks, SQLite, and persistent data/public volumes.
